Release Notes (Shrink)

v66 (November 21, 2026)

  • Added: A new "Merge only" card appears when you select multiple videos, joining them without compression.
  • Improved: The Save button on the completion screen always stays in the same place; Recompress appears below it only when needed.
  • Improved: The Save button looks the same as usual even when the target size is exceeded.
  • Fixed: Selecting just one video no longer leaves the previous merge list behind and switches to merge mode.
  • Other: Improved internal behavior.

v49 (November 19, 2026)

  • Fixed: Fixed an issue where preset cards could not be reordered by long-pressing.
  • Improved: Buttons are now less likely to be pressed unintentionally while scrolling a screen.
  • Other: Improved internal behavior.

v30 (November 17, 2026)

  • Improved: Added a divider line and shadow between the fixed and scrolling parts of screens for better readability.
  • Improved: The scrollbar on the compression screen is now hidden.
  • Other: Improved internal behavior.

v13 (November 14, 2026)

  • Fixed: Fixed an issue where cards stayed tilted after stopping a preset reorder midway.
  • Improved: The screen no longer turns off automatically during compression.

v1 (November 13, 2026)

  • Initial release
