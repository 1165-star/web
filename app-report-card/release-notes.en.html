Release Notes (App Report Card)

v112 (2026-11-10)
  • Improved: After restoring from a backup, home screen widgets now show the latest data
v96 (2026-11-08)
  • Added: Settings now has a “Skin” option (carried over from the former “Theme”)
  • Added: Added a setting to fit the chart’s vertical axis to the maximum of the visible range (on by default)
  • Improved: Improved the look of line charts (line thickness, curves, points, axis text)
  • Improved: Days with no data are now bridged by a line connecting the days before and after
  • Other: Improved internal behavior
v88 (2026-11-05)
  • Added: The Installs tab now shows a churn rate trend (uninstalls over 7 days ÷ active devices)
  • Added: Reviews whose rating or text changed are now marked “Updated” and highlighted on the Ratings tab together with new reviews
  • Added: For updated reviews, you can now see the rating change (e.g. ★2 → ★4) and the previous text
  • Added: The Ratings tab icon now shows the number of new and updated reviews, and a “Mark as checked” button was added
  • Improved: The alert shown after fetching data now also covers updated reviews
v82 (2026-11-04)
  • Improved: Language names, such as the translation target, now show the language code after them
  • Improved: The confirmation before sending a reply now shows the rating, name, and comment of the review being replied to
v65 (2026-11-03)
  • Added: Reviews can now be translated and shown in your display language
  • Added: Replies are now translated into the reviewer’s language, previewed, and sent in that language
  • Added: When editing a reply, your current reply is now translated into your language and shown in the input field
  • Added: Sent replies can now be translated into your display language
  • Added: Added a copy link to replies
  • Improved: A confirmation dialog now shows what will be sent before you send a reply
  • Improved: A full-screen indicator now shows progress while sending a reply and while downloading language data
  • Fixed: Fixed an issue where the “Send” text in the confirmation dialog was wrong
v46 (2026-11-01)
  • Added: Added a “Daily rating” line chart to the Ratings tab
  • Improved: In demo mode, dates now follow the latest date in the data
  • Improved: The “System default” font option is now previewed in your device’s font
  • Improved: Improved the look of dialogs such as the update notice
  • Improved: Improved the look of input fields (fill, border, selected state, and placeholder color) for better readability
  • Improved: Ad revenue under 1 yen is now shown with decimals, like ¥0.43
  • Fixed: Fixed an issue where restoring from a backup could result in empty data
  • Fixed: Fixed an issue where the end of some text was cut off
