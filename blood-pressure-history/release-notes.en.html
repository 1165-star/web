Release Notes (BP Notebook)

v77 (October 28, 2026)

  • The home screen now shows the Health Connect sync history (latest 5 entries).
  • Added “System default” to the fonts and made it the default.
  • Improved an issue where text could look broken or be cut off on some devices.
  • Unified the look of dialogs such as the update notice.
  • Minor bug fixes and performance improvements.

v65 (October 26, 2026)

  • The weekly graph widget is now a line chart that fills the whole frame, with thicker lines and larger text.
  • Changed the order of items on the settings screen.
  • Added a “required” icon to systolic and diastolic pressure, and to the reminder weekdays and notification text.
  • The record edit popup now opens more lightly.
  • The graph screen now responds faster after a tap.
  • Improved the tap response of buttons and input fields.
  • Input fields now share the same height, with the text centered vertically.
  • Improved the backup encryption method and made the storage size estimate more accurate.
  • Reviewed how temporary files are handled when exporting a backup, for better stability.
  • Minor bug fixes and performance improvements.

v30 (October 22, 2026)

  • Data storage has been renewed. Your records and settings carry over automatically the first time you open the app after updating.
  • New backup format: backups made with earlier versions can't be restored. Please create a new backup after updating.
  • Restoring is safer: data is checked first, and your current data is kept if anything fails.
  • After a restore, PREMIUM status, Health Connect setting and update-notice status stay as on this device. Reminders are turned off.
  • If you try to restore a backup made by a newer version, you'll be asked to update the app.

v27 (October 21, 2026)

  • Health Connect integration is now available in the free version too.

v17 (October 15, 2026)

  • The entry screen now starts with your previous values right after the app launches.
  • Fixed an issue where Health Connect sync failed after restarting the app.
  • Fixed the weekday labels being cut off in the graph calendar.
  • Fixed the app version display.

v15 (October 15, 2026)

  • Fixed some display issues.

v1 (October 11, 2026)

  • Initial release
