更新履歴(スタミナ手帳)

最終更新日: 2026年10月28日

v80 (2026-10-28)

  • 通知をオフにしても通知が届く問題を修正しました
  • タイムラインの並び替え時に、項目がスムーズに動くようにしました
  • スタミナカードの時刻表示を見直し、ゲーム名を広く表示しました
  • フォントに「システム標準」を追加しました
  • 表示の細かな不具合を修正し、ダイアログのデザインを統一しました

v50 (2026-10-25)

  • 設定画面の項目の並びを、フォント、テーマ、言語、バックアップ、このアプリについての順に変更しました
  • バックアップの形式を新しくしました（以前の形式のバックアップも復元できます）
  • バックアップの書き出し処理を改善し、動作を安定させました
  • 復元時に必要な空き容量の見積もりを見直しました
  • バックアップや復元の処理中の画面に、タイトルを表示するようにしました
  • 添付ファイルが大きい場合でも、バックアップと復元が安定して動くように改善しました
  • パスワード入力画面で、ボタンが枠からはみ出して背景が透けて見える問題を修正しました
  • パスワード入力画面で、背景をタップしたり、無効な「完了」ボタンを押したりすると画面が閉じてしまう問題を修正しました
  • 端末の文字サイズ設定に合わせて、画面全体の大きさや余白が自然に変わるようにしました
  • ボタンやアイコンなどのタップできる部分を広げ、押しやすくしました
  • ボタンや入力欄をタップしたときの反応を改善しました
  • 入力欄や選択欄の高さをそろえ、文字が上下中央に表示されるようにしました
  • 下部のタブの文字が、上下中央に表示されるようにしました
  • 項目名の「必須」表示を、見やすいアイコンに変更しました
  • アプリの動作を軽くするための最適化を行いました

v27 (2026-10-20)

  • データの保存方式を刷新しました。これまでのデータは、更新後の最初の起動時に自動で引き継がれます
  • バックアップ・復元の仕組みを新しくしました
  • 旧バージョンで作成したバックアップは、この版では復元できません。更新後にあらためてバックアップを作成してください
  • 更新後は一度アプリを開いてください。ウィジェットは、アプリを開くまで表示が空になることがあります

v20 (2026-10-16)

  • ホーム画面ウィジェットが4種類に（次の予定1件・1×1の小型・一覧・ゲーム別）
  • ウィジェットにゲームのアイコン画像を表示
  • 一覧は高さに合わせて件数が変わり、進捗バーも表示
  • 次の予定1件と1×1の小型ウィジェットは無料（一覧・ゲーム別はPREMIUM）
  • ウィジェット右側の時刻・「満タン」が切れる問題を修正
  • ゲーム編集・スタミナ編集で、スクロール開始時にダイヤルが開く問題を修正
  • 設定の「このアプリについて」にバージョンを表示

Release Notes (Stamina Notebook)

Last updated: October 28, 2026

v80 (2026-10-28)

  • Fixed an issue where notifications were still delivered even after turning them off
  • Items now move smoothly when reordering the timeline
  • Revised the time display on stamina cards and made the game name wider
  • Added "System default" to the font options
  • Fixed minor display issues and unified the design of dialogs

v50 (2026-10-25)

  • Reordered the items on the Settings screen: Font, Theme, Language, Backup, About this app
  • The backup format has been renewed (backups in the previous format can still be restored)
  • Improved the backup export process for more stable operation
  • Revised the estimate of free space required for restoring
  • The processing screens for backup and restore now show a title
  • Backup and restore now run reliably even with large attachments
  • Fixed the buttons on the password screen sticking out of their frame and showing the background through
  • Fixed the password screen closing when you tap the background or press the disabled "Done" button
  • The overall size and spacing of screens now adapt naturally to the device's text size setting
  • Enlarged the tappable area of buttons, icons and other controls to make them easier to press
  • Improved the response when tapping buttons and input fields
  • Made input and selection fields the same height, with text centered vertically
  • Text in the bottom tabs is now centered vertically
  • Changed the "Required" mark on item names to an easier-to-see icon
  • Optimized the app to run lighter

v27 (2026-10-20)

  • The way data is stored has been renewed. Your existing data is carried over automatically the first time you open the app after updating
  • Backup and restore have been reworked
  • Backups created with an older version cannot be restored in this version. Please create a new backup after updating
  • Please open the app once after updating. Until then, widgets may appear empty

v20 (2026-10-16)

  • Home screen widgets now come in four types (next entry, tiny 1x1, list, per game)
  • Widgets show the game's icon image
  • The list fits its height and shows progress bars
  • The next-entry and 1x1 widgets are free (list and per-game are PREMIUM)
  • Fixed the time / "Full" text on the right of widgets being cut off
  • Fixed the dial opening by mistake when you start scrolling on the edit screens
  • The version is now shown in "About this app"

v1 (2026-10-07)

  • Initial release
