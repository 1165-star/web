v80 (2026-10-28)
  • Fixed an issue where notifications were still delivered even after turning them off
  • Items now move smoothly when reordering the timeline
  • Revised the time display on stamina cards and made the game name wider
  • Added "System default" to the font options
  • Fixed minor display issues and unified the design of dialogs
v50 (2026-10-25)
  • Reordered the items on the Settings screen: Font, Theme, Language, Backup, About this app
  • The backup format has been renewed (backups in the previous format can still be restored)
  • Improved the backup export process for more stable operation
  • Revised the estimate of free space required for restoring
  • The processing screens for backup and restore now show a title
  • Backup and restore now run reliably even with large attachments

  • Fixed the password screen closing when you tap the background or press the disabled "Done" button
  • The overall size and spacing of screens now adapt naturally to the device's text size setting
  • Enlarged the tappable area of buttons, icons and other controls to make them easier to press
  • Improved the response when tapping buttons and input fields
  • Made input and selection fields the same height, with text centered vertically
  • Text in the bottom tabs is now centered vertically
  • Changed the "Required" mark on item names to an easier-to-see icon
  • Optimized the app to run lighter
v27 (2026-10-20)
  • The way data is stored has been renewed. Your existing data is carried over automatically the first time you open the app after updating
  • Backup and restore have been reworked
  • Backups created with an older version cannot be restored in this version. Please create a new backup after updating
  • Please open the app once after updating. Until then, widgets may appear empty

  • The list fits its height and shows progress bars
