Release Notes (Point Compass)

v124 (November 8, 2026)

  • Added a skin (color scheme) selection screen that lets you choose while previewing.
  • Improved internal behavior.

v104 (November 3, 2026)

  • Unified the look of input fields, buttons, chips and checkboxes so borders and states are easier to read.
  • Adjusted the placeholder (example) text color in input fields to be easier to see.
  • The lucky direction (Eho) now shows the current calendar year (e.g. 2026 throughout 2026).
  • Fixed the right-edge border of input fields and buttons appearing cut off.
  • Fixed the app closing when opening the map.

v81 (October 30, 2026)

  • You can now register a place by dropping a pin on a map.
  • Improved internal behavior.

v67 (October 28, 2026)

  • Unified the look of the update notification dialog with the standard design (it no longer closes when you tap the background)
  • Added "System default" to the font choices and made it the initial value when no setting exists
  • Fixed an issue where text weight varied depending on the device or settings

v51 (October 25, 2026)

  • Added the directions of the 12 zodiac signs based on your birthday, with their altitude (your own sign is highlighted at the top)
  • Changed the order of items in Settings to: Birthday, Font, Color theme, Language
  • Adjusted the compass update interval to 0.7 seconds for lighter operation
  • Adjusted the header height and centered its content vertically
  • Adjusted the height of selection fields and the padding of buttons
  • Error and success colors now match the selected color theme
  • Improved how the database is exported, making backups more reliable
  • The app now automatically follows your device's appearance setting (light/dark)
  • Fixed an issue where the colors of the needle image were cut off partway

v15 (October 20, 2026)

  • The current app version is now shown under "About this app" in Settings
  • Improved how data is stored on your device for better stability (your existing data is carried over automatically at launch)
  • Updated backup and restore to work with the new storage method

v1 (October 9, 2026)

  • Initial release
