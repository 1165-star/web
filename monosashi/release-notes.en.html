Release Notes (Monosashi)

v48 (2026-10-28)
  • Improved: Tapping a photo on the results screen and photo list now shows its trend chart
  • Improved: Added "System default" to the font options and made it the initial value when no setting exists
  • Improved: Adjusted text weight and alignment so text is less likely to display incorrectly
  • Improved: Redesigned the update notice dialog
v32 (2026-10-25)
  • New: Added the Let-go record and Let-go reminder features
  • Improved: Reordered the items on the Settings screen
  • Improved: Added an icon to the password field label to show it is required
  • Improved: Unified the height of selection fields for a tidier look
  • Improved: Unified screen colors with the theme colors
  • Improved: Renewed the data storage method for better stability
  • Improved: Made exporting backup data more stable
v15 (2026-10-20)
  • New: Let-go record. Select "Unnecessary" photos, tap "Let go", and log whether you threw away, sold or gave away each item. Includes monthly counts
  • New: Let-go reminder. If you haven't opened the app for a while, you'll get one reminder after 7, 14 or 30 days. Set it in Settings
  • New data storage. Your data is carried over automatically on first launch after updating
  • Backups from earlier versions can no longer be restored. Please create a new backup after updating
