Release Notes (めものわ (Memonowa))

v76 (2026-10-28)
  • Added "System default" to the fonts and made it the initial setting when none is saved.
  • Adjusted the look and spacing of dialogs and update notices.
  • Fixed an issue where the connection was lost if the screen was recreated during collaborative editing.
  • Improved stability.
v57 (2026-10-24)
  • Changed the order of items on the settings screen.
  • Removed "Erase all" from the settings screen.
  • You can now save an edited image for posting on X from the shared drawing panel and a photo of two devices.
  • Made communication with nearby devices more secure (authentication, encryption, and split transfer of large images).
  • Improved backup encryption (earlier backups can still be restored).
  • Added icons to the field labels on the backup password entry.
  • You are now asked to confirm when there is not enough free storage.
  • Adjusted tap responsiveness and vertical layout.
  • Adjusted the height of the pen customization sheet.
  • Stabilized screen movement while the keyboard is shown.
v24 (2026-10-20)
  • Added a version display to the settings screen.
  • Renewed how data is stored. Backups made before this update can no longer be restored.
v11 (2026-10-10)
  • New "Reset to blank" button at the top right (clears the drawing and background; while drawing together, only the host can use it)
  • The background image used while drawing together is now kept after restarting the app and after you stop sharing
  • Fixed unresponsive buttons in input pop-ups and cut-off text on the PREMIUM screen
v1 (2026-10-10)
  • Initial release
